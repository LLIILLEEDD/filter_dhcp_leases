# Архив перед подготовкой рабочей поставки

## Что где находится

- `pre_production_2026-10-16/` — точный снимок прежних файлов, включая старый
  README, Python-модули, первоначальные тесты, учебный TXT, WSL-инструкцию,
  схему PNG и промпт, `lab/`, базу лиз, резервные копии и кэш.
- `manifest.json` — исходные пути, размеры и SHA-256 каждого сохранённого файла.
- `tests/` — рабочие копии тестов с актуальными импортами и именами.
- `tests/fixtures/demo.leases` — синтетический пример, восстановленный
  из сохранённой резервной копии; первоначального `demo.leases` в корне
  на момент переноса уже не было.

Снимок хранится для возврата и обучения. Его содержимое не переписывалось
при переименовании программы. Старые имена и команды в этих документах
относятся к сохранённой версии. Рабочие имена в корне:

| Прежде | Теперь |
| --- | --- |
| `dhcp_leases.py` | `filter_dhcp_leases.py` |
| `dhcp_service.py` | `dhcp_service_manager.py` |
| `dhcp_leases.log`, по умолчанию | `filter_dhcp_leases.log` |

Ни архив, ни тесты не нужны на сервере для запуска программы.
Исходная база и копии намеренно не возвращены в корень рабочей поставки.

имена модулей, но порядок выполнения программы остался тем же.

## Проверки текущей версии

Запускай из корня проекта, а не из каталога снимка:

```bash
python3 -B -m unittest discover -s archive/tests -p "test_*.py" -v

python3 -B filter_dhcp_leases.py \
  -i archive/tests/fixtures/demo.leases \
  -s 10.201.90.0/24 \
  --check-date "2026/08/18 10:20:00" \
  --dry-run --verbose
```

Ожидается 12 исходных блоков, 3 выбранных IP и 8 оставшихся блоков.
Оригинальные тесты в снимке оставлены для истории; их адаптированные копии:

- `tests/test_filter_dhcp_leases.py` — обработка базы и CLI;
- `tests/test_dhcp_service_manager.py` — работа с systemd и восстановление.

## Сохранность и Git

При переносе каждый файл снимка сверен с SHA-256 в `manifest.json`.
База лиз, старые копии, кэш и материалы не удалялись.
Папка `.git` сохранена в корне и не относится к поставке на сервер.

Снимки `pre_production_*` и локальные результаты исключены через `.gitignore`.
Актуальные тесты, синтетический пример и описание архива можно хранить
в репозитории. Наличие правила игнорирования не изменяет уже существующую
Git-историю.
